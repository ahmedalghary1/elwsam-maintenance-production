# الوسام للتشغيل والصيانة

تطبيق Android موحّد يجمع تطبيق الصيانة وتطبيق الإنتاج والأعطال مع تسجيل دخول واحد وشاشة اختيار حسب دور المستخدم.

## البناء

يتطلب Android SDK 36 وJDK 17. على Windows شغّل:

```bat
BUILD_APK.cmd
```

الحزمة الناتجة: `release-output/elwsam-operations-release.apk`.

> إعداد Release الحالي موقّع بمفتاح Debug مثل التطبيقين الأصليين. يجب استبداله بمفتاح المؤسسة قبل التوزيع الرسمي أو النشر في متجر.
